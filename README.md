# 붉은 사막 (Crimson Desert) 정보 페이지

펄어비스의 오픈월드 액션 어드벤처 **붉은 사막(Crimson Desert)** 에 대한 리서치 결과를 정리한 정적 웹페이지입니다.

## 보기

- 로컬: `index.html` 을 브라우저로 열기
- GitHub Pages 배포 시: 저장소 **Settings → Pages → Branch: `main` / root** 선택 후 `https://kjuhwa.github.io/CrimsonDesert/` 에서 확인

## 페이지 구성

| 페이지 | 내용 |
|---|---|
| `index.html` | 게임 개요, 스토리 & 세계관, 플레이어블 캐릭터, 게임플레이, 평가 & 판매 기록, 로드맵, PC 시스템 요구사항 |
| `quests.html` | 메인 퀘스트 데이터베이스 — 프롤로그 + 12개 챕터 + 에필로그, 31개 퀘스트 라인 / 140+ 세부 퀘스트, 진행 팁 |
| `items.html` | 아이템 데이터베이스 — 유니크 무기·방어구 획득처와 효과, 목적별 추천 장비, 요리·연금술 소비 아이템 |
| `bosses.html` | 보스 공략 — 주요 스토리 보스 11종 전략, 월드 보스와 드랍 장비, 공통 준비·전투 팁 |
| `regions.html` | 지역 정보 — 파이웰 5대 지역 + 어비스 하늘 계층, 지역별 거점·권장 레벨·콘텐츠, 지도 자료 |

## 기술

프레임워크 없는 순수 HTML + CSS 정적 사이트 (공용 스타일: `assets/style.css`). 외부 의존성은 Google Fonts뿐입니다.
