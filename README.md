# 붉은 사막 (Crimson Desert) 정보 페이지

펄어비스의 오픈월드 액션 어드벤처 **붉은 사막(Crimson Desert)** 에 대한 리서치 결과를 정리한 정적 웹페이지입니다.

## 보기

- 로컬: `index.html` 을 브라우저로 열기
- GitHub Pages 배포 시: 저장소 **Settings → Pages → Branch: `main` / root** 선택 후 `https://kjuhwa.github.io/CrimsonDesert/` 에서 확인

## 담고 있는 내용

- 게임 개요 (개발사, 출시일, 플랫폼, 가격, 엔진)
- 스토리 & 세계관 (파이웰 대륙, 회색갈기 용병단, 어비스)
- 플레이어블 캐릭터 3인 (클리프 / 다미안 / 웅카)
- 게임플레이 시스템 (전투, 탐험, 생활 콘텐츠, 하우징)
- 평가 & 판매 기록 (메타크리틱 77, 누적 600만 장+, 수상 이력)
- 업데이트 로드맵 (인핸스드, DLC '미지의 여정' 2026-10-15)
- PC 시스템 요구사항

## 기술

프레임워크 없는 순수 HTML + CSS 단일 페이지 (`index.html`). 외부 의존성은 Google Fonts뿐입니다.
